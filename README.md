# 🌦️ Weather App

A modern and responsive Weather App built using **HTML, CSS, and JavaScript**. The application allows users to search for any city and view real-time weather information through a clean and user-friendly interface.

## 🚀 Features

* 🔍 Search weather by city name
* 🌡️ Displays current temperature
* 💧 Shows humidity and weather conditions
* 🌬️ Displays wind speed
* 📱 Responsive design for desktop and mobile
* 🎨 Attractive UI with a modern background

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Weather API
